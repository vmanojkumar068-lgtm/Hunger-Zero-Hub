# Hunger Zero Hub — Food Donation & Waste Reduction Platform

## 📌 Project Overview

Hunger Zero Hub is a web development project designed to connect surplus-food donors with people in need. The platform aims to reduce food waste and improve food accessibility by helping donors share available food and coordinate with potential recipients.

## ✨ Key Features

* **Food Donation Listings:** Allows surplus food to be listed for donation.
* **User Registration:** Supports users joining the platform.
* **Food Availability Tracking:** Helps users view available donated food.
* **Donor–Recipient Coordination:** Facilitates coordination between food donors and recipients.
* **User-Friendly Interface:** Provides a simple interface for accessing platform features.
* **Food Waste Reduction:** Encourages the redistribution of surplus food to people who need it.

## 🛠️ Technologies Used

* Java
* HTML5
* CSS3
